进入辽港集团体系 · 策略建议

两大方向 · 四条路径分析框架（港口·海洋工程防腐）· 精简版
核心结论

辽港集团（招商局集团旗下、辽港股份 601880）统一管理辽宁大连/营口/丹东/盘锦/绥中五港，采购归口"辽港阳光采购平台"。进入体系有两大方向：

一、材料供应（只供材料，不施工）
① 技术合作与示范工程：对接港务技术部/水运设计院 → 示范工程实证 → 纳入防腐技术规格与合格供应商
② 采购平台入库与直接供货：辽港阳光采购平台（cg.liaoningport.com）注册入库 → 钢结构零修 / 储罐防腐修理类项目供货
二、工程分包（材料 + 施工）
③ 在役设施防腐翻新：码头钢结构 / 储罐 / 混凝土承台翻新招标（带锈免喷砂 + 一级资质优势）
④ 新建港区工程：通过水运工程设计院 / EPC 切入新建泊位，写入技术规格书

建议：以"示范工程 + 采购平台入库投标"双线先行切入，中期布局工程分包；以 GB 30981.2-2025（2026-06-01 实施）水性合规升级为贯穿性卖点。

港口属典型海洋高腐蚀环境：浪溅区 / 潮差区干湿交替、氯离子主导、北方港口叠加冬季冻融与海冰冲击。下表将辽港设施部位逐项映射到水性 EAU 复合树脂涂层体系，明确"哪里有需求、用什么产品切"。

水性 EAU 对港口的四大差异化切入点：
① 合规窗口——GB 30981.2-2025《涂料中有害物质限量 第2部分：工业涂料》2026-06-01 起执行，VOC 限值加严；水性 EAU 面漆 VOC<80g/L，契合港口涂料水性化合规升级方向。
② 认证对等——C5-VH 系统检测报告 TW 230737（化学工业海洋涂料质量监督检验中心），国内极少数通过 ISO 12944 C5-VH 的水性体系，与 Jotun / Hempel / PPG 溶剂型产品同级。
③ 带锈免喷砂——PB-GA005 可直接涂覆于 St2/St3 打磨面与带锈基面，破解港口在役翻新"喷砂受限、要求不停产"的核心痛点。
④ 密闭空间安全——水性以水为分散介质，消除火灾与职业病隐患，适应地下翻车房、储罐内壁、受限外场等港口典型场景。

三、材料供应

分两种模式：

模式①：技术合作与示范工程

运作方式：对接辽港集团技术中心 / 各港务公司技术部，或联合水运工程设计院（中交水规院、一航院等）、大连本地港口设计力量，以示范工程 / 试点为载体建立技术认可，推动水性 EAU 写入港口防腐技术规格书与合格供应商名录。GB 30981.2-2025 合规升级与辽港股份 ESG / 绿色港口战略（已发布 17 项生态环保管理制度）是核心切入点。

+ 集团 / 港务层面技术认可，建立竞争壁垒，带动长期供货
+ 示范工程是后续供货与工程分包的实证基础（带锈翻新 + 密闭空间案例可直接背书）
+ 契合辽港绿色港口与 ESG 导向，政策窗口期（2026-06-01 新标执行）正当其时
- 周期较长（6~12 个月），决策链与设计院分散，需逐港 / 逐设计院对接
- 结果存在不确定性，需持续跟进与资源投入

模式②：采购平台入库与直接供货

通过"辽港阳光采购平台"（cg.liaoningport.com，微信小程序同名）实现。平台采用邀请码注册制，供应商获采购方邀请码后注册、上传资质、完善资料审核入库。

运作方式：完成平台注册入库后，跟踪并参与各港务公司钢结构年度零修、储罐防腐修理、栏杆及钢构件维修等询比采购与公开招标（此类项目辽港已有实际公告），以材料供应商身份供货。

+ 项目信息透明公开，覆盖五港真实维护需求
+ 水性防腐在港口采购品类中认知尚待建立，存在先发占位机会
+ 公司持有防水防腐保温工程专业承包一级 ✓，资质门槛满足
- 邀请码注册制，需先获得采购方邀请入库，主动性受限 入库流程待确认
- 与既有溶剂型品牌（Jotun / Hempel / 国内品牌）存在价格竞争
- 防腐材料是否作为独立集采品类分类 待确认

四、工程分包（材料 + 施工）

路径③ 在役港口设施防腐翻新

运作方式：参与码头钢结构、原油 / 化工储罐、混凝土承台的防腐翻新公开招标，承接含材料 + 施工的防腐工程分包。水性 EAU 的带锈免喷砂特性直接对应港口"在役作业区喷砂受限、要求不停产"的刚需；公司防水防腐保温工程专业承包一级 ✓满足多数项目资质门槛。

+ 存量市场大：港口重防腐维护周期 5~10 年，每年有稳定维修需求
+ 带锈免喷砂契合港口不停产翻新痛点，是相对国际品牌的差异化抓手
+ 一级防腐资质 ✓ + 市政公用总承包二级 ✓，资质组合占优
+ 可积累港口 / 海洋工程业绩，为后续项目背书
- 评标通常要求港口或海洋工程防腐业绩证明（首单门槛较高）
- 水上 / 高空施工窗口短，对施工组织与快干、一道高膜厚要求高

路径④ 新建港区工程

运作方式：在设计阶段介入，通过水运工程设计院（中交水规院 / 一航院等）将水性 EAU 写入技术规格书，或与 EPC 总包合作承接新建泊位 / 港区的防腐工程分包。

+ 项目体量大，从头植入水性方案利于技术锁定
+ 可在技术规格书中锁定 C5-VH 水性配套，形成长期壁垒
- 决策链长：设计院 → EPC 总包 → 业主（辽港股份 / 港务公司）
- 新建泊位数量有限、周期较长
- 需设计院关系 + EPC 合作双重资源 设计院关系待建立

五、路径选择建议

第一阶段（0~6 个月）· 示范工程 + 平台入库双线并行
· 示范工程：对接辽港技术中心 / 选定 1~2 个港务公司，以在役钢结构带锈翻新或混凝土承台防护做水性 EAU 示范点，建立实证与口碑——占位要点：借 GB 30981.2-2025（2026-06-01 执行）合规窗口，水性化升级正当其时，示范工程一旦落地即形成有力的技术背书。
· 平台入库：推动辽港阳光采购平台邀请码注册与资质入库，跟踪钢结构零修 / 储罐防腐修理类项目，尽早参与投标积累供货业绩。

第二阶段（6~12 个月）· 供货深化 + 技术规格植入
· 借示范工程业绩，参与各港务公司防腐材料供货与询比采购，形成稳定供货关系。
· 联合水运设计院推动水性 EAU 写入新建项目技术规格书，从源头植入水性 C5-VH 方案。

第三阶段（12 个月+）· 工程分包规模化
· 利用一级防腐资质，承接码头钢结构 / 储罐 / 混凝土承台翻新工程分包，积累港口海洋工程业绩。
· 形成"材料供应 + 工程分包"双驱动，覆盖大连 / 营口 / 丹东 / 盘锦 / 绥中五港。

附：市场规模结论

单港区：材料供应口径约 90~320 万元；工程分包口径（材料 + 施工）约 180~960 万元。港口重防腐维护周期 5~10 年，单港区年度维护约 20~140 万元。

全集团（大连 / 营口 / 丹东 / 盘锦 / 绥中五港，3-5 年渗透）：工程分包口径中性约 2~4 亿元；材料供应口径中性约 0.8~1.5 亿元。

市场基础：辽港集团 2025 年货物吞吐量 4.83 亿吨、集装箱 1204 万 TEU；辽宁沿海万吨级以上泊位居全国第五，存量钢结构、混凝土、储罐、罩棚等设施防腐维护市场可观。
