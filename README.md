# EAU-Protection · 产品推荐方案库

> **新乘® · 水性 EAU 复合树脂防腐涂料体系** — 产品推荐方案集中托管与发布仓库
>
> 苏州高新大乘低碳环保新材发展有限公司

本仓库通过 **GitHub Pages** 发布面向客户场景的防腐涂装试点与配套方案，每个方案为一个独立 HTML 页面。

## 在线访问

- **首页索引**：<https://eau.mahadow.com/>
- 单个方案：`https://eau.mahadow.com/<文件名>.html`

## 仓库结构

```
EAU-Protection/
├── index.html                          # 方案库首页索引（列出全部方案卡片）
├── Offshore-Wind-Power-re-coating.html # 海上风电运维重涂客户试点方案
├── CNAME                               # GitHub Pages 自定义域名（eau.mahadow.com）
└── README.md
```

## 维护约定

1. **只新增，不删除、不覆盖** 仓库内已有文件。
2. 每个方案 = 一个独立 HTML 文件，命名用 **英文 + 连字符**（如 `Offshore-Wind-Power-re-coating.html`），与现有文件保持一致。
3. 新增方案后，同步在 `index.html` 的「方案列表」中追加一张卡片（同样只增不删）。
4. **对外材料不出现产品价格信息。**
5. 产品参数以内部知识库为准，不自行推测。
6. `CNAME` 为 Pages 域名绑定文件，请勿改动。

## 关于 EAU

**EAU** = Eco-friendly Adhesive Unity（生态环保互穿网络交联复合树脂技术）

核心竞争力：**环保合规 + 卓越物理性能 + 施工便捷**

| 指标 | 数值 |
|------|------|
| 附着力 | ≥ 5 MPa |
| 耐久年限 | C5VH 认证 > 25 年 |
| VOC | < 80 g/L |
| 碳足迹 | 仅溶剂型的 30%–50% |
